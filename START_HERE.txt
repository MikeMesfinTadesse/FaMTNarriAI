-----------------------------------------
☸️ PART 1: KUBERNETES IN GIT BASH (Windows Cluster)
-----------------------------------------

2. Go to your project folder:
   cd /d/Main_Hua_Master/AI_Workspace/Personal_Projects/Poject_FAMTNarraai/FaMTNarriAI-dockerv3

   minikube start

5. Open your app in the browser:

6. Stop the cluster when finished:
   minikube stop

☸️ PART 2: KUBERNETES IN UBUNTU (Main WSL Cluster)
-----------------------------------------
1. Open "PowerShell" (Windows Start menu -> type PowerShell).
2. Enter the Linux environment:
   wsl
3. Go to your Linux DevOps folder:
   cd ~/devops
4. Start the Linux Minikube cluster:
   minikube start --driver=docker
5. Wait 30 seconds, then verify it says "Ready":
   kubectl get nodes
6. Go to your Windows project folder from inside Linux:
   cd /mnt/d/Main_Hua_Master/AI_Workspace/Personal_Projects/Poject_FAMTNarraai/FaMTNarriAI-dockerv3
7. Deploy your app to Linux Kubernetes:
   kubectl apply -f k8s/deployment.yaml -f k8s/service.yaml
8. Verify the Pods are "Running":
   kubectl get pods
9. Open your app in the browser:
   minikube service famtnarriai-service
   (Press Ctrl+C in Ubuntu when you are done looking at the app).
10. Stop the cluster when finished:
    minikube stop

🛑 THE GOLDEN RULE FOR SHUTDOWN
--------------------------------------------------------------------
Before you turn off your PC, ALWAYS run "minikube stop" in 
whatever terminal you were using (Git Bash, Ubuntu, or PowerShell). 
This prevents the corrupted SSH errors we fixed earlier!

If Minikube breaks: 
Run "minikube delete" and then "minikube start" again.

-----------------------------------------
🏗️ LESSON 4: ANSIBLE (CONFIGURING LOCAL SERVERS)
-----------------------------------------
Ansible is how companies install software on physical servers 
without clicking buttons. It uses SSH and text files.

1. Open Ubuntu terminal (PowerShell -> wsl).
2. Create your Ansible workspace:
   mkdir -p ~/devops/ansible-lab && cd ~/devops/ansible-lab
3. Install Ansible (if not already installed):
   sudo apt install ansible-core -y
4. Create an inventory file:
   nano inventory.ini
   (Paste: [local] and localhost ansible_connection=local)
5. Create your playbook:
   nano install_nginx.yml
   (Paste the YAML code for tasks)
6. Allow passwordless sudo (needed for Ansible to work):
   echo "$USER ALL=(ALL) NOPASSWD: ALL" | sudo tee /etc/sudoers.d/99-ansible-nopasswd
7. Run the playbook:
   ansible-playbook -i inventory.ini install_nginx.yml
